# changelog

The changelogs of the versions before this one, one file per version.
What is being written now is `CHANGELOG.md` at the root; a version that
has been superseded is moved here as `CHANGELOG-{version}.md`, and
`CHANGELOG-archive.md` holds the entries of the legacy crates of v0.8
and earlier.

These files say what was written at the time. They describe the
OS-shaped lineage the v0.16 re-foundation removed, not the code in this
workspace.
