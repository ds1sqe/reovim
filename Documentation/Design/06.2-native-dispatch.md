# Native module registration and request dispatch

Native registration, binding and pending-request boundary. The
[declaration format](06-declarations.md) owns method/value semantics.
The [state provider](06.3-state-providers.md) defines editing/factory staging callbacks;
they are not ordinary control callbacks that may mutate live Buffer state.

## Borrowed call data and owned results

```c
#include <stddef.h>
#include <stdint.h>

/* Common statuses; the callback defines which subset it can return. */
enum {
    RV_OK = 0, RV_NOT_READY = 1, RV_CLOSED = 2, RV_BUSY = 3,
    RV_INVALID = 4, RV_DENIED = 5, RV_UNSUPPORTED = 6,
    RV_PRESSURE = 7, RV_CONFLICT = 8, RV_UNAVAILABLE = 9,
    RV_CANCELLED = 10, RV_PROVIDER = 11, RV_GAP = 12, RV_INCOMPLETE = 13
};
enum { RV_POLL_PENDING = 0, RV_POLL_READY = 1 };
enum { RV_CANCEL_ACCEPTED = 0, RV_CANCEL_TOO_LATE = 1 };
enum { RV_OUTCOME_OK = 0, RV_OUTCOME_FAILED = 1, RV_OUTCOME_UNKNOWN = 2 };

typedef uint64_t rv_access; /* Token scoped to a supplied caller context. */
typedef struct { uint8_t epoch[16]; uint64_t serial; } rv_identity;
typedef struct { const uint8_t *ptr; size_t len; } rv_bytes;
typedef struct { const rv_access *ptr; size_t len; } rv_refs;
typedef struct { rv_bytes data; rv_refs refs; } rv_args;
typedef struct { uint32_t code; rv_identity detail; } rv_error;

typedef struct {
    void *context;
    void (*wake)(void *context);
    void (*retain)(void *context);
    void (*release)(void *context);
} rv_wake;

typedef struct {
    uint32_t status;
    uint32_t activity; /* Known READ=1, WRITE=2, STATUS=4; metadata policy. */
    rv_error error;
    rv_args value;
    void *owner;
    void (*release)(void *owner);
} rv_outcome;
```

Null with zero length is an empty span; other null/length inconsistencies
reject. Lengths are bounded before copying/decoding. Tokens carry no authority
outside the caller context that issued them. All-zero error detail means absent;
a nonzero identity is metadata and grants no access. The original pending
request owns provider recovery state. Error fields cannot grant hidden Resource
access.

status uses RV_OUTCOME_OK, RV_OUTCOME_FAILED or RV_OUTCOME_UNKNOWN. Admission
errors return from submit before provider execution. An admitted
provider cannot retroactively label an effect as never admitted. FAILED means
the operation's declared terminal failure; UNKNOWN retains effect/recovery
ownership. value on OK matches the bound output declaration. UNKNOWN carries
no returned access. Empty data means no progress evidence; nonempty data matches
the bound progress declaration. This permits a host-detected provider fault to
retain uncertainty without fabricating a valid provider value. FAILED carries
empty data and references; its error records the declared failure.
Activity reports only known events allowed by the declaration; see metadata.

rv_outcome.owner retains all result spans and references until release. take
transfers that owner once to Runtime; Runtime validates/copies data and adopts
reference ownership before releasing it. Provider result release does not close
already adopted caller handles. Invalid results still have an owned cleanup
path.

## Pending request vtable

```c
typedef struct rv_pending_ops {
    size_t bytes;
    uint32_t (*poll)(void *context, rv_wake wake);
    uint32_t (*take)(void *context, rv_outcome *output);
    uint32_t (*cancel)(void *context);
    uint32_t (*reconcile)(void *context); /* Optional; continues original work. */
    uint32_t (*finish)(void *context);
} rv_pending_ops;

typedef struct {
    void *context;
    const rv_pending_ops *ops;
} rv_pending;

typedef struct {
    size_t bytes;
    uint32_t (*exec)(void *context, const rv_args *input,
                     rv_pending *output, rv_error *error);
} rv_exec_ops;

typedef struct {
    size_t bytes;
    uint32_t (*ioctl)(void *context, uint32_t command, const rv_args *input,
                      rv_pending *output, rv_error *error);
} rv_control_ops;
```

poll returns PENDING or READY and never transfers the result. If it retains a
wake beyond the callback, it calls retain and eventually release. A wake is a
progress signal, not a result or permission to execute under Core authority.

Exported tables/records with bytes begin with that size field. For this fixed
0.1.0 ABI, producers set sizeof(the declared record) and consumers require
an exact match before reading callbacks. Required callbacks must be nonnull;
reconcile and unoffered interface-family tables may be null. This is a layout
check, not a version negotiation system. Pointer extents/alignment remain native
caller obligations; shape checks cannot make arbitrary invalid pointers safe.

take returns OK once per outcome generation when READY, otherwise NOT_READY or
CLOSED. It fills output only on success; repeated take cannot duplicate returned
ownership. cancel
requests cancellation, returning ACCEPTED or TOO_LATE. Neither return value
proves an external effect did not happen; the final outcome supplies that fact.

After UNKNOWN has been taken, reconcile may return OK to start a new outcome
generation on the same context. poll/take then supplies refined evidence for the
same effect/input, never a new exec/ioctl. Existing copied outcomes remain
immutable. BUSY joins no new generation; absent support returns UNSUPPORTED.
Final OK/FAILED outcomes cannot be reopened. Runtime serializes request
callbacks and does not poll a taken generation until reconciliation has started
another. Recovery/delivery readers share one Runtime-owned result; they do not
each call native take. Refinement cannot duplicate adopted output ownership.

finish releases request context only when no pending execution, output or
cleanup obligation remains. It returns OK and invalidates context, or BUSY while
Runtime retains it. Runtime never calls a table after OK. Caller Drop/disconnect
requests cancel and schedules finish; Runtime owns outstanding cleanup. New
request/access admission reserves bounded cleanup capacity before returning.

Exec/control begin returns RV_OK with one initialized pending owner, or an error
with no effect, retained input or pending output. This permits allocation
failure without constructing another allocation-backed failure future. The host
already admitted the request, so such failure is terminal FAILED, not
pre-admission rejection. Once an effect may have started, begin must return a
pending owner that settles or reports UNKNOWN. output is untouched on error;
error is filled only on error. Malformed tables fence the provider and retain
its code/context; invalid callbacks are not called.

Exec/control begin receives input spans borrowed for that callback. Runtime's
request owns copied argument bytes and scoped input references. A provider
needing bytes across callbacks must retain its own copy or an explicitly granted
data access; it cannot hold arbitrary caller stack storage. Scoped references
remain valid through request settlement. Longer retention requires capture.

## Provider exports and instance lifetime

```c
typedef struct rv_edit_ops rv_edit_ops;
typedef struct rv_factory_ops rv_factory_ops;
typedef struct rv_open_ops rv_open_ops;
typedef struct rv_io_ops rv_io_ops;
typedef struct rv_namespace_ops rv_namespace_ops;
typedef struct rv_write rv_write;
typedef struct {
    size_t bytes;
    void *context; /* Bound to this interface's operation tables. */
    rv_bytes declaration;   /* Canonical InterfaceDecl, including its ApiId. */
    const rv_exec_ops *exec;
    const rv_control_ops *control;
    const rv_edit_ops *edit;
    const rv_factory_ops *factory;
} rv_interface;

typedef struct {
    size_t bytes;
    void *context;
    const rv_interface *interfaces;
    size_t interface_count;
    const rv_open_ops *open;
    const rv_io_ops *io;
    const rv_namespace_ops *namespace_ops;
    uint32_t (*stop)(void *context);
    void (*destroy)(void *context);
} rv_provider;

typedef struct {
    size_t bytes;
    void *context;
    uint32_t (*stage)(void *context, rv_bytes path,
                      const rv_provider *provider);
} rv_registrar;
```

The loader supplies a registrar scoped to the module's authorized mount and a
caller context containing its imports/Host grants. Relative publication paths
cannot escape that mount; an empty relative path denotes the mount itself.
stage copies the path/declaration bytes and export
metadata, retains immutable callable tables/code, and validates complete
declarations, ABI table availability, limits and ownership. It transfers
provider ownership only on success; failure leaves it with the module. Host code
contains no ELF/NTFS/Parse branch. Table absence is explicit unsupported
capability.

Staged providers are invisible until module initialization succeeds and the
Runtime atomically installs the batch. Failure retains rollback responsibility
and releases staged providers outside registry/commit guards. No partially ready
provider is discoverable. Module ABI entry/version and configured loading remain
the existing common loader boundary, not a new domain-specific entry symbol.

stop fences provider-specific activity and returns OK or BUSY. It is not a
destructor; a stopped instance may remain alive for retained access/results.
destroy runs once only after stop succeeds and all Runtime-held calls, accesses,
states and result owners using that provider are released. Its implementation
may free the provider context; executable module code remains loaded through it.
Failed cleanup remains owned and visible to the lifecycle authority.

Each interface's exec/control/edit/factory callbacks receive its own context.
The provider retains that context and its tables through all pending/result
cleanup. I/O, namespace, open, stop and destroy use the provider context. There
is no implicit fallback between these contexts or extra API selector on exec.

## Complete example path

An ELF module provides elf_control_begin, its pending table and an instance
containing already initialized structural state. It builds one rv_interface
using ELF_CONTROL_ID and the two methods in 06-declarations.md; its
control table sets bytes=sizeof(rv_control_ops) and ioctl=elf_control_begin.
The provider context is that ELF instance. During initialization:

```c
/* elf_provider is the module-owned initialized rv_provider above. */
uint32_t publish_elf(rv_registrar registrar, const rv_provider *elf_provider) {
    static const uint8_t path[] = "elf";
    rv_bytes name = { path, sizeof(path) - 1 };
    return registrar.stage(registrar.context, name, elf_provider);
}
```

After the module's contribution batch is published, callers bind this offered
interface under [operation selection](01.2-operations.md) and use its
[declared values](06-declarations.md). The instance context remains
private to the ELF module; generic host code contains no ELF branch.

## Native/service equivalence

No pointer from these records crosses the service transport. A service binding
uses a caller-scoped token that retains the same Resource/interface; a request
uses its original identity, family and ioctl number when applicable. The
canonical value bytes and separately translated references are identical in
meaning to the native arguments. Request/delivery custody survives handle close.

The [I/O/watch tables](06.4-io-providers.md) and state tables use these ownership rules.
