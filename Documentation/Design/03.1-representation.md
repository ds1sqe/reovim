# 03.1 — Representation and semantic values

A Representation reads Buffer state as Domain values and maps semantic edits
back to that state. Its semantic space identifies one lifetime of this mapping;
replacing the interpretation makes positions from the old space stale.

```text
// One Buffer contains "# Draft". Both representations read that same state.
source view:  Text characters and positions in the source
preview data: Markdown heading with label "Draft"
// The Client renders either view. Neither creates another authoritative copy.
// A text position and a heading identifier are different coordinate systems.
```

Types:
[Resource access](01.2-resource-access.md), [BufferState](02-buffer.md),
[BufferChange](02.1-history.md).

[Clients](04-clients.md) render the semantic data. Representation
implementations are [providers](06.1-providers.md) consuming public Domain/model
APIs; they do not supply Kernel-owned view layout or drawing.

## Qualified values

```rust
// Path: kernel/interface/src/semantic/value.rs
// Module: interface::semantic::value
pub trait RepresentationSchema {
    const NAME: &'static str; // Declared contract name, not Rust TypeId.
    const VERSION: u32; // Exact supported value/operation contract version.
    type Snapshot; // Immutable semantic data or bounded leased sparse access.
    type Delta; // Domain-defined change between exact observations.
    type Position; // Location/object/time; no universal scalar or byte offset.
    type Selection; // May describe disjoint parts or leased domain masks.
    type Edit; // Semantic intent, never a native plan or undo callback.
}

pub struct Observed {
    pub representation: ResourceId, // This interpreted access, not its source.
    pub space: ResourceId,          // Interpretation/correspondence lifetime.
    pub buffer: BufferState, // Exact working state behind the observation.
}
pub struct Position<Schema: RepresentationSchema> {
    pub observed: Observed,
    pub value: Schema::Position, // Units/meaning belong to the selected schema.
}
pub struct Selection<Schema: RepresentationSchema> {
    pub observed: Observed,
    pub value: Schema::Selection, // Not necessarily a range or two endpoints.
}
pub struct Edit<Schema: RepresentationSchema> {
    pub observed: Observed,
    pub value: Schema::Edit, // Semantic intent encoded by the API helper.
}

// Path: clients/core/src/cursor.rs; module: client_core::cursor
pub struct Cursor<Schema: RepresentationSchema> {
    pub position: Option<Position<Schema>>,
    pub selection: Option<Selection<Schema>>,
}
```

Access validates the declared name/version and compatibility. Conflicting
declarations cannot replace a contract silently. Changing interpretation or
correspondence replaces space and fences old values.

Values come from actual observations. Same backing or a newer revision alone
proves no correspondence. Old values require explicit mapping/revalidation:
exact, partial, ambiguous, stale, unsupported and unrepresentable remain
distinct. Partial mapping names omitted meaning and requires explicit
acceptance; no universal translation algorithm is selected.

[Navigation providers](06.3-module-composition.md) return these same qualified
positions/selections. Discovering a function or selecting its extent adds no
editing authority; only a subsequent semantic edit can change Buffer/History.

Cursor belongs to Client policy. Zero/multiple cursors or selection alone are
valid; combined values require coherent Buffer/space/state. Server retention
does not give Kernel follow/drawing policy. Authored masks/styles use Edit.

## Observation

```rust
// Path: kernel/interface/src/semantic/observation.rs
// Module: interface::semantic::observation
pub struct Snapshot<Schema: RepresentationSchema> {
    pub id: ResourceId, // Retained immutable semantic read view/lease.
    pub observed: Observed,
    pub value: Schema::Snapshot, // Owned typed value or lease-qualified access.
}
pub enum RepresentationUpdate<Schema: RepresentationSchema> {
    Snapshot(Snapshot<Schema>),
    Delta {
        before: Observed, // Exact required semantic predecessor.
        after: Observed,
        value: Schema::Delta,
    },
    Invalidated {
        before: Observed,
        after: Observed, // New state qualifier, not replacement semantic data.
    },
    Changed(BufferChange), // Actual acceptance, not an installation command.
}
pub struct RepresentationObservation<Schema: RepresentationSchema> {
    pub snapshot: Snapshot<Schema>,
    pub watch: ResourceId, // Subsequent typed updates after this snapshot cut.
}
```

Observe creates snapshot and watch at one coherent boundary, or fails without
a ready watch. Read-only interpretation needs no editable lowering or
whole-state copy. Missing/unsupported content cannot become an empty snapshot;
interpretation failure cannot reverse an accepted edit.

Delta installation checks watch, Representation, space and exact predecessor.
Invalidation supplies no content. Acceptance and interpretation may arrive in
either order; correlate request/state. [Delivery](03-observation.md) owns
gap/end and retry rules; this is one event path.

## Edit through the observed view

```rust
// Proposed Text SDK; its profile supplies find_unique and Replace.
let view = text.observe(representation).await?;
let range = text.find_unique(&view.snapshot, "Draft")?; // Observed text units.
let request = Edit {
    observed: view.snapshot.observed,
    value: Replace(range, "Plan".into()),
};
let changed = text.edit(&request).await?; // Accepted Buffer now reads "# Plan".
// Intervening edits make the request stale. A read-only view rejects editing.
```

## Access and edits

Optional typed helpers use the same Resource request path:

| Call | Result |
| --- | --- |
| attach(buffer) | This caller's Representation Resource over existing state/History |
| observe(representation) | RepresentationObservation with a separate snapshot/watch |
| edit(request) | Actual BufferChange after semantic validation and acceptance |
| release_snapshot(snapshot) | Release this read access; direct borrows remain pinned |
| detach(representation) | End interpreted access without closing the shared Buffer |

Attach grants interpreted access under the exact schema; await successful
observe before using semantic values. Edit validates grants, schema, live
space, meaning and exact Buffer state. Read-only access rejects
unsupported/denied edits.

Runtime prepares and Core [accepts](03.2-editing.md). High-level edits preserve
unrepresented source units. Clients submit no native plans or chosen result
versions; success returns the actual BufferChange.

## Recovery and release

```text
gap -> stop dependent updates -> observe a fresh coherent boundary
  -> fence old delivery -> switch observation -> explicitly unwatch old watch
// Failure keeps the old access and loss evidence.
// A new observation does not reconstruct missing transitions.
// Other observers remain independent.
```

Each observe owns a separate snapshot/watch. Metadata copies add no lease;
closing a request record does not release returned snapshots. Snapshot values
and arrays are SDK-owned. release_snapshot is idempotent; checked sparse reads
may then return snapshot-expired, while direct views remain pinned through their
borrow. Admitted edits capture needed input before handoff.

Detach fences access and ends its watches within bounds. Buffer, accepted
outcomes and separately owned snapshots survive. Incomplete teardown retains
owners and exposes failure; snapshot release/result cleanup remain usable.
Owners bound subscribers, snapshots and work under [memory](02-buffer.md) and
[request lifetime](01.3-requests.md).
