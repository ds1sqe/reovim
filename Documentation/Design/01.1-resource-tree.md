# 01.1 — Resource tree

The namespace is a tree of names resolving to [Resources](01-resources.md).
Names find subjects; their supported contracts define what access means.

```text
resource/connection/
  input                   // Receive datagrams.
  output                  // Send datagrams explicitly.
  info                    // Read endpoint metadata.
modules/treesitter/        // Alias to a selected instance in this scope.
  info                    // Declared exports and input/result contracts.
  parse                   // Write a source reference to request parsing.
```

Each endpoint has a ResourceId. The endpoint owner defines its behavior;
tree position implies no byte, seek, save or editing interface. A command
accepts the whole request at its own Resource, without a separate call child.
Ordinary private fields and individual arguments need no tree entries.

```rust
// Proposed common SDK; kernel is this caller's granted connection.
let connection = kernel.resolve("resource/connection").await?;
let children = kernel.children(connection).await?;
let input = kernel.resolve_at(connection, "input").await?;
// Resolving/inspecting never sends data or activates a module.
```

## Names and lookup

```rust
// Path: kernel/interface/src/namespace.rs; module: interface::namespace
use alloc::boxed::Box;

pub struct ResourceEntry {
    pub name: Box<str>, // Owned listing value; directory entries stay private.
    pub resource: ResourceId, // Copying retains and grants nothing.
}
```

The namespace provider privately owns names, directory entries and indexes.
Paths are queries; returned names are owned values without growth capacity.
Rename changes neither an earlier listing nor an existing ResourceId.

| Common SDK call | Meaning |
| --- | --- |
| root() | This connection's authorized namespace root |
| resolve(path) | Resolve relative to that root |
| resolve_at(parent, path) | Resolve relative to an accessible Resource |
| children(parent) | Coherent authorized ResourceEntry values in name order |

Paths use `/`; `""` names the parent. Reject leading slash, empty segments,
dot/dot-dot and traversal outside the grant. Check each component before
revealing it. Borrowed paths are captured before queuing.

Listings contain unique names and are caller-owned copies, not leases.
Oversized complete listings return pressure; this profile does not page or
require each Resource to enumerate its data units. Lookup/listing use the
ordinary [request outcomes](01.2-resource-access.md).

## Identity and lifetime

Aliases may name the same subject. Listings are tree-shaped; references can
form graphs. Rebinding a name never retargets an old ID or admitted request.
Removing names grants no editing, shared-close or provider-unload authority.

Input, output and info have separate grants. Endpoint close fences new work
and late installation, then settles pending requests. Captures and snapshots
keep their own owners; unwatching input leaves output alive. Directional
shutdown needs an explicit endpoint contract.

[Modules](06-modules.md) owns instance scope. [Access](01.2-resource-access.md)
owns writes and independently retained readers; neither lifetime follows from
a pathname. Capture, publication and tree removal remain separate operations.
