# 01.2 — Resource access

Use caller access, a Resource and a request. Runtime checks the contract,
grants and readiness, retains the selected provider and executes the request.
The caller awaits the result.

```rust
// Proposed common SDK; snapshot and parse_contract are supplied inputs.
// The exact contract comes from public declarations or authorized info.
let parse = kernel.resolve("modules/treesitter/parse").await?;
let input = Message::reference(parse_contract, snapshot);
let reply = kernel.write(parse, &input).await?;
// A module helper can encode this request; the common SDK knows no parser.
```

## Common values

A message carries encoded data and Resource references. The contract names
their meaning and exact version, including input/result encoding. Each module
owns its schemas; Kernel routes messages without interpreting domain values.

```rust
// Path: kernel/interface/src/access.rs; module: interface::access
use alloc::boxed::Box;

pub struct Contract {
    pub name: Box<str>, // Owned contract name; registry storage stays private.
    pub version: u32,   // Exact version, not a minimum.
}
pub struct Message {
    pub contract: Contract,
    pub data: Box<[u8]>, // One complete encoded value, possibly empty.
    pub resources: Box<[ResourceId]>, // Ordered references in this namespace.
}
impl Message {
    pub fn reference(contract: Contract, resource: ResourceId) -> Self {
        Self { contract, data: Box::new([]), resources: Box::new([resource]) }
    }
}
pub enum RequestError {
    Rejected(Error), // Known not to have been admitted; no requested effect.
    Failed(Error),   // Terminal error with no outstanding effect recovery.
    Unknown {
        cause: Error,
        recovery: Box<str>, // Required locator for this exact request lifetime.
    },
}
```

The common envelope preserves the byte sequence and ordered reference slots.
A reference-only input has empty data and one reference. Structured schemas
define their data encoding and slot usage; unknown schemas cannot be decoded
by guessing. Resource references travel in these slots, never as unchecked
pointer bits or foreign numeric IDs. Adapters translate and check each slot.
Each contract defines every slot's allowed use and ownership. Owned result
access is adopted once and released through close; borrowed references add
no ownership. This envelope does not make Resources byte-addressed.

Every call identifies an exact contract. The endpoint must support that
contract and its registered input/result schema; mismatches reject. Replacing
a provider or alias cannot change an admitted request's contract. Metadata
advertises support; it grants neither execution nor interpretation authority.

## Reads, writes and helpers

| Common SDK call | Result and behavior |
| --- | --- |
| read(subject, request) | Message under the requested read contract |
| write(subject, request) | Message from submitting one complete request |
| watch(subject, contract) | Independent subscription Resource; see observation |
| close(access) | End caller-owned access; settle its work and direct borrows |

Calls await completion and return `Result<_, RequestError>`. Resolution and
listing follow the same outcomes. An empty Message can request metadata;
read-at inputs carry a position under their own schema. Stream consumption,
random access and message boundaries remain properties of the selected
interface. A Resource need not support every method.

At a command endpoint, one write is one request. Incomplete/oversized input
rejects before execution; partial stream writes never trigger that command.
An adapter assembles and validates framing first. There is no shared argument
staging or shared last-result slot. Inspection is passive; only an authorized
write requests the action. Writing a selection query needs query authority,
not Buffer-edit authority. Every referenced source needs its own allowed use.

Requests borrow caller input; SDK/Runtime capture needed data and references
before handoff, including when the caller drops its wait. Received messages
are SDK-owned. No public queue slots, credits or provider contexts are needed.

Module API packages supply optional typed helpers over this same access.
They encode/decode their contract and preserve its errors and ownership;
they contain no live provider implementation. Generic tools can use the
common envelope and published schemas directly. New commands add no common
SDK field, Kernel enum variant or Kernel specialization. Exact native/wire
layout belongs to the [adapter](06.4-native-modules.md).

## Independent access and failure

A connection is a caller's granted access to one Runtime, including for
embedded modules. Composition may supply narrower caller access. Independent
cursors, watches, Representations and snapshots use their own Resources;
sharing a connection or source does not merge their state or grants.

Close ends that access, not a shared Buffer or backing subject. Shared close
requires the owner's explicit command and grant. Metadata copies acquire no
lease; direct views stay pinned through their borrows. Returned Resources
keep their own lifetimes after the request record is released.

Unresolved effects return a result Message with required recovery evidence;
Failed cannot discard that obligation. Rejected proves no admission; Failed
reports a settled error, without promising that no effect occurred.

`Unknown` carries recovery even for an ordinary awaited write. It does not
mean the write failed or may be repeated.
[Interrupted requests](01.3-requests.md) owns recovery and retention.
Provider tables and contexts belong to [composition](05.1-composition.md).
