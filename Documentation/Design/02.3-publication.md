# Save, export and Save As

Types: [Resource access](01.2-operations.md), [BufferState](02-buffer.md).
Runtime captures selected data, backing and conflict evidence at admission;
callers construct no publication-base bookkeeping.

The examples use one default backing role; [sources](02.2-sources.md) also
support multiple named roles. Saving uses the selected state and explicit target
mapping, never graph traversal. There is no generic inverse of a transformation.
A writable derived view declares lowering that preserves opaque/unaffected units
and validates source invariants; a view can instead be read-only or export-only.

```rust
// Proposed SDK; Buffer contains "# Plan", its file backing still has "# Draft".
let saved = publication.save(&buffer.state).await?;
// Applied: selected state was published; later Buffer edits stay unsaved.
// Unbound: use Save As to create a target and associate it with this Buffer.
// OutcomeUnknown: reconcile this request's evidence before any retry.
```

| Call | What changes |
| --- | --- |
| save | Publish selected state to the Buffer's retained backing |
| export | Publish to another destination; keep backing and unsaved status |
| save_as | Publish, then associate the new backing if the Buffer is still current |

[Namespace rename](01.1-namespace.md) moves a name while preserving identity.
Publication instead writes selected content and may create a different subject.

## Effects and results

Proof is the selected interface's achieved boundary, not a universal revision
or disk-durability promise.

```rust
// Path: kernel/interface/src/resource/effect.rs
// Module: interface::resource::effect
use alloc::boxed::Box;

pub enum Effect<Proof> {
    Applied(Proof), // Exactly the effect guaranteed by this interface.
    DefinitelyNotApplied(Error), // Proved absence of the requested effect.
    OutcomeUnknown {
        cause: Error,
        recovery: Box<str>, // Required locator, including after reconnect.
    },
    PartiallyApplied {
        cause: Error,
        recovery: Box<str>, // Retain ownership until settled or transferred.
        atomicity_violated: bool, // True if an offered atomic guarantee failed.
    },
}

// Path: kernel/interface/src/publication.rs; module: interface::publication
pub struct PublicationProof {
    pub selected: BufferState, // Exact state actually published.
    pub target: ResourceId,    // Actual destination, including a new subject.
    pub evidence: ResourceId,  // Required retained proof record.
}
pub enum AssociationDisposition {
    NotAttempted, // Publication was not proved fully applied.
    Associated(BufferDescriptor), // Same Buffer/History, new backing observed.
    NotAssociated(Error), // Publication applied, but association did not.
}
pub struct SaveAsResult {
    pub publication: Effect<PublicationProof>,
    pub association: AssociationDisposition,
}
```

Required evidence identifies request, target and completion boundary;
reserve retention before handoff. Optional Error.id details cannot carry this
duty.

Unknown/partial effects retain the original work and a required recovery
locator under [request recovery](01.3-requests.md). Reconcile that work and
read revised results; never resubmit publication as recovery. Release waits
for settlement or transfer. Proof ID copies pin nothing; Buffer retains its
base independently.

SaveAsResult permits Associated/NotAssociated only with Applied publication;
other effects use NotAttempted. Associated preserves Buffer/History identity
and names the proof's target. Applied plus NotAssociated means the target
changed but a concurrent edit/close/rebind prevented association; report both
outcomes. Never delete that target automatically to simulate rollback.

## Requests and calls

Destination is the selected contract's authorized target/create request;
Format selects encoding.

```rust
// Path: kernel/interface/src/publication.rs; module: interface::publication
pub struct PublicationRequest<Destination, Format> {
    pub selected: BufferState, // Real observation, not retained data by itself.
    pub destination: Destination, // Owned value; no implicit source rebinding.
    pub format: Format,        // Compatible typed encoding selected explicitly.
}
```

Runtime validates contracts/grants before target resolution. Admission retains
coherent selected data for save/export/Save As and captures borrowed input
before handoff. Caller inputs remain unchanged; later edits are excluded.

Target access, overwrite grant and conflict evidence are independent checks.
Unsupported guarantees reject; default creation does not overwrite.

Save retains its target/base through handoff and revalidates; rebind cannot
redirect it and conflict cannot refresh its precondition. Joined callers use
the same owner-retained base. Only Applied for the same live association and
matching prior base advances that base. Late results cannot overwrite newer
association/evidence; preserve their actual outcomes separately. Mark only the
selected state published. Failure preserves working state/History.

Save As requires compatible future publication, proved application and a
still-current Buffer observation. Association invalidates old observations
without a History node. Unknown/partial publication cannot associate or
advance a base.

Before handoff, proved rejection may return an ordinary error. After handoff,
report Effect certainty; cancellation/timeout/lost replies imply no rollback.
RequestError::Unknown is failed result observation; Effect::OutcomeUnknown is
a received unresolved-effect result. Atomic contracts flag partial application
as a violated guarantee; visibility and crash durability remain distinct.

## Multiple targets

```rust
buffer.publish(expected, targets, PublishPolicy::Atomic).await?;
```

PublishTarget contains source key, destination ResourceId and optional expected
base Snapshot. WRITE access is acquired under the invoking caller, not borrowed
from another client's creator context. The publisher prepares the mapping and
conditional update; reading the source or knowing its ID supplies no grant.
Atomic requires one declared commit authority for all targets; otherwise it
returns Unsupported before publication. Independent permits separate conditional
updates and returns per-target Applied/Conflict/Unsupported/Unknown outcomes.
Default save uses Atomic. Neither mode weakens filesystem-enforced conditions.

Publication retains the selected state/base/targets through reconciliation. Only
confirmed applied targets update saved/base evidence. A later edit remains
unpublished. Aggregate state can publish to one composite target or several
explicit targets; no traversal order invents merge or recursive save semantics.
B.save to Buffer A applies through A's preparation/Core authority and stops
there.

Export grants no WRITE on the original source.
Two Buffers sharing a source retain independent bases;
publishing one leaves the other's state/History unchanged.

## File profile and caller

This adapter profile creates without overwrite and preserves source encoding.
Existing-target replacement needs a selected contract, grant and conflict
condition. Names are authorized namespace values; native handles stay private.

```rust
// Path: resource/file/src/contract.rs; module: file_resource::contract
use alloc::boxed::Box;

pub struct FileLocation {
    pub directory: ResourceId, // Authorized destination namespace subject.
    pub name: Box<[u8]>, // One lossless namespace name.
}
pub enum FileFormat {
    Source, // Preserve source units; not an implicit text conversion.
}
```

```rust
// Proposed file-publication helper; buffer is an unnamed Buffer observation.
// directory/name identify an authorized destination; inputs are borrowed.
let request = PublicationRequest {
    selected: buffer.state,
    destination: FileLocation { directory, name },
    format: FileFormat::Source,
};
let save_as = publication.save_as(&request).await?; // SaveAsResult.
// Associated supplies the new observation for subsequent save.
// NotAssociated leaves the Buffer usable and the target effect visible.
// The target ResourceId comes from proof; never fabricate it before create.
```

## Save workflow

A semantic save service may apply configured preparation, such as rustfmt,
before requesting publication. This is an awaited Client-command or Kernel
module workflow; the low-level publication call still publishes its selected
state. [Observation](03-observation.md) cannot impose this ordering.

```rust
// Proposed SDK; source, formatter and publication access are granted.
// Formatter returns Some(edit) or None for no change; it cannot save files.
let source = source_representation.observe(representation).await?;
let formatting = formatter.format(&source.snapshot).await?; // Exact input.
let selected = match formatting {
    Some(value) => {
        let request = Edit { observed: source.snapshot.observed, value };
        source_representation.edit(&request).await?.after
    }
    None => source.snapshot.observed.buffer, // No extra History entry.
};
let saved = publication.save(&selected).await?; // Exact accepted BufferState.
// Await acceptance before saving; never substitute an unrelated latest state.
```

The workflow owns formatter order and admitted work until settled. External
execution and waiting occur outside Core authority. Formatting uses normal
semantic edit validation and History; an intervening edit invalidates stale
formatter output. Reobserve/recompute within declared bounds or return a
conflict. Later edits remain outside the selected publication.

Formatting failure/cancellation stops this workflow unless the caller
explicitly selected a policy permitting an unformatted save. Publication
failure leaves an accepted formatting edit in Buffer/History; it does not
undo that edit. After publication handoff, existing effect/recovery rules apply.

If every Client must obey a shared preparation policy, expose the coordinated
save service to those Clients and grant raw publication only to that service.
Equivalent third-party Clients then use the same public path. A Client-local
hook alone establishes no guarantee for other callers that retain direct
publication authority.
