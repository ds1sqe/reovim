## Why Heritage?

These documents represent the intellectual foundation of Reovim's design:

- **Design proposals** - The original vision that guided implementation
- **Strategy docs** - Methodologies that shaped our development process
- **Deferred proposals** - Ideas preserved for future phases
- **Superseded docs** - Previous architectures replaced by newer designs
